# FRONTEND + DESIGN

Load for UI/UX/frontend tasks.

Before creating UI:
- find canonical components;
- inspect design tokens;
- inspect similar screens;
- inspect responsive behavior;
- reuse existing icons, forms, modals, notifications and loading patterns.

Always consider:
responsive, accessibility, keyboard, semantic HTML, loading, empty, error, permission, optimistic state, hydration, bundle/performance, XSS and browser behavior.

Visual QA when available:
RENDER → INSPECT → FIX → RENDER AGAIN.

Do not create raw styling that bypasses an existing design system without justification.
