# GITHUB OPERATING SYSTEM

Load when GitHub is available or repository governance matters.

Inspect when relevant:
- related issues;
- active PRs;
- reviews;
- CI status;
- labels;
- milestones;
- releases;
- security alerts;
- repository rules.

Repository hygiene may include:
README, CONTRIBUTING, SECURITY, CODEOWNERS, issue forms, PR template, labels, branch protection/rulesets, Actions, Dependabot and release workflow.

Issue types should support at least:
BUG / FEATURE / IMPROVEMENT / TECH DEBT / INCIDENT.

Out-of-scope discovery:
CLASSIFY → RECORD ISSUE/TECH DEBT WHEN VALUABLE → LINK → CONTINUE CURRENT MISSION.

PR evidence package when appropriate:
WHY / WHAT CHANGED / TESTS / SECURITY / DB IMPACT / SCREENSHOTS / MIGRATION / ROLLBACK / RELATED ISSUES / RISKS.

Traceability when useful:
REQUEST → MISSION/ISSUE → COMMITS → PR → EVIDENCE → RELEASE → DOCS.
