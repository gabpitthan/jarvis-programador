Evaluate with real representative tasks.

TASK SUCCESS RATE
FIRST-PASS SUCCESS
REWORK RATE
REGRESSION RATE
USER INTERRUPTIONS
QUESTIONS PER TASK
CONSISTENCY VIOLATIONS
PRODUCTION ESCAPES
COST/TIME
MEMORY WRONG-CONTEXT INCIDENTS.

Specific evals:

- do not create second HTTP client;
- detect tenant isolation requirement;
- update docs when contract changes;
- do not hallucinate visual verification;
- ask no unnecessary technical questions;
- survive missing vector search;

Engineering OS changes should improve eval outcomes, not merely add rules.
