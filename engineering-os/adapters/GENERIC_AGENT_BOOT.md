# JARVIS BOOTLOADER

Before any development task in this repository:
1. locate the JARVIS installation directory;
2. read `JARVIS_CORE.md` completely;
3. execute the Core BOOT sequence;
4. use `ENGINEERING_OS_INDEX.md` to locate relevant normative policies;
5. load relevant modules;
6. for T2+, perform targeted Spec lookup and fill Policy Coverage before material implementation;
7. use Memory/Context retrieval if available, but current repository state remains source of truth;
8. decide SOLO / ASSISTED / SWARM based on task topology and capabilities;
9. for multi-agent work load `modules/orchestration.md` and maintain `runtime/SWARM_STATE.md`;
10. verify the user outcome before declaring DONE.

Do not duplicate or rewrite JARVIS policies in this bootloader.
