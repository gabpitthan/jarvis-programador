# JARVIS QUICKSTART

## 1. Instale

Extraia o pacote no repositório, preferencialmente em um diretório estável como `.engineering/jarvis/`.

## 2. Configure o bootloader da sua CLI

Faça o arquivo de instrução persistente da CLI apontar para:

`JARVIS_CORE.md`

Ele deve obrigar o agente a executar o BOOT e usar Index/Spec/Modules conforme necessário.

## 3. Rode o bootstrap uma vez

```text
Leia BOOTSTRAP_PROMPT.txt e instale/adapte o ENGINEERING OS para este projeto. Faça discovery, baseline, capability detection, canonicals e validação antes de considerar o setup pronto.
```

## 4. Programe normalmente

```text
Jarvis, adiciona exportação CSV de clientes.
```

ou

```text
Jarvis, quero sistema de equipe com convites e permissões por área.
```

## 5. Não gerencie os agentes

JARVIS escolhe:
SOLO / ASSISTED / SWARM.

Você só deve ser interrompido por decisão real de produto, permissão, ação perigosa ou blocker genuíno.

## 6. Resultado esperado

Uma única resposta final contendo:
- o que foi implementado;
- o que foi verificado;
- decisões importantes;
- riscos restantes;
- ação sua, se houver.

Para detalhes completos, leia `HOW_TO_USE_JARVIS.md`.


## Model routing

If multiple models/providers are configured, do nothing special: describe the outcome normally. Jarvis should route roles automatically. You may optionally constrain providers, budget, agent count or execution mode.
