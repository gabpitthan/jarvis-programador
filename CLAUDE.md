# JARVIS BOOT

Este repositório é a fonte canônica do ENGINEERING OS / JARVIS. Ele não é um projeto de aplicação: é a política de engenharia que governa todos os outros.

Antes de qualquer tarefa:

1. leia `engineering-os/JARVIS_CORE.md` por completo e execute o BOOT definido nele;
2. carregue `engineering-os/ENGINEERING_OS_INDEX.md`;
3. classifique a task T0–T4 e selecione módulos por `engineering-os/runtime/MODULE_ROUTER.md`;
4. para T2+, faça o lookup dirigido da Spec segundo `engineering-os/runtime/SPEC_LOOKUP_PROTOCOL.md` e preencha `engineering-os/runtime/POLICY_COVERAGE.md` antes de mudança material;
5. decida SOLO / ASSISTED / SWARM; para multi-agente carregue `engineering-os/modules/orchestration.md` e mantenha `engineering-os/runtime/SWARM_STATE.md`;
6. verifique o resultado real antes de declarar DONE.

Mudanças neste repositório são mudanças no ENGINEERING OS: carregue também `engineering-os/modules/evals.md`.

Não duplique política aqui. Este arquivo é bootloader, não constituição.
