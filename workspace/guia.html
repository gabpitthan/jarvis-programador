Konnex Workspace

Vários projetos, vários CLIs, ao mesmo tempo

Como abrir o Claude num projeto e o Codex noutro, em paralelo, sem que um atrapalhe o outro. Você não precisa entender de programação — são três comandos e três teclas.

• A ideia em uma frase

Antes dos comandos, o modelo mental. O resto decorre disto.

Sala Cada projeto é uma sala Whitelabel é uma sala. A landing é outra. Elas ficam abertas em paralelo, cada uma com o seu trabalho rodando dentro.
Aba Cada CLI é uma aba Dentro de uma sala, o Claude é uma aba e o Codex é outra. Você troca de aba para trocar de assistente no mesmo projeto.

1 Preparar o projeto (uma vez só)

Isto liga o Jarvis no projeto. Não abre nada — só arruma. Faz uma vez na vida de cada projeto.

terminal
$ jarvis add /root/whitelabel-whaticket
registrado como 'whitelabel-whaticket' (perfil: producao)

$ jarvis add /home/claudeuser/konnex-lp --profile lite
registrado como 'konnex-lp' (perfil: lite)

Perfil? É o “grau de rigor” do Jarvis. producao é o completo, para o que está no ar de verdade. lite é enxuto, para landing e experimentos. Projetos no mesmo perfil seguem a mesma política; perfis diferentes são independentes.

2 Abrir um projeto com um CLI

Aqui a tela vira o assistente, já dentro da pasta certa. Você conversa normal.

terminal
$ jarvis up whitelabel-whaticket claude
sessão 'whitelabel-whaticket', janela 'claude' pronta
→ a tela vira o Claude Code, dentro do Whitelabel

Quer o Codex mexendo na landing ao mesmo tempo? Solte esta sala (veja as teclas abaixo) e abra a outra:

terminal
$ jarvis up konnex-lp codex
→ o Codex trabalha na landing; o Claude segue vivo no Whitelabel

3 As três teclas que você precisa

As salas rodam num programa chamado tmux. Só isto basta para se virar.

  • Ctrlbentãod Soltar a sala
    Sai deixando tudo rodando lá dentro. É assim que você larga o Claude trabalhando e vai fazer outra coisa. (o “d” é de detach)
  • Ctrlbentãow Ver tudo que está aberto
    Abre a lista de salas e abas. Você anda com as setas e entra na que quiser.
  • Ctrlbentão1 Pular direto para uma aba
    Dentro da sala, o número troca de aba na hora: 1, 2, 3… (Claude, Codex…)

4 Ver o que está aberto

A qualquer momento, num terminal limpo:

terminal
$ jarvis ls
== projetos registrados ==
nome                   caminho                      perfil
whitelabel-whaticket   /root/whitelabel-whaticket   producao
konnex-lp              /home/claudeuser/konnex-lp   lite

== sessões tmux vivas ==
whitelabel-whaticket: 2 windows   (Claude trabalhando)
konnex-lp: 2 windows              (Codex trabalhando)

≡ Todos os comandos

Para consultar quando precisar. No dia a dia você usa só o up.

ComandoO que faz
jarvis add <caminho> [--profile <nome>]Prepara um projeto (uma vez). Sem --profile, usa o producao.
jarvis up <nome> [claude|codex]Abre/volta para a sala do projeto, na aba do CLI escolhido.
jarvis lsLista os projetos e as salas que estão abertas agora.
jarvis down <nome>Fecha a sala do projeto (encerra o que estava rodando nela).
jarvis profilesMostra os perfis de política que existem.
jarvis profile new <nome>Cria um perfil novo que diverge sozinho, sem afetar os outros.
jarvis clisMostra quais assistentes estão instalados no servidor.

? Se travar

“Perdi a tela / não sei onde estou.”
Aperte Ctrl+b e solte, depois w. Aparece a lista de tudo que está aberto; entre na sala com as setas.

“Fechei o terminal por engano.”
Tudo bem — as salas continuam vivas no servidor. Abra um terminal e rode jarvis ls para vê-las, e jarvis up <nome> para voltar.

“Quero dois trabalhos no mesmo projeto sem se atrapalharem.”
Isso pede uma cópia separada da pasta (worktree). Peça ao assistente: ele monta para você.
